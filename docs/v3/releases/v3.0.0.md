# Poyraz UI v3.0.0

Status: stable candidate. The exact npm package, registry artifacts, immutable tag and
production smoke are created from one reviewed master commit by the protected release workflow.

Major scope was frozen on **2026-07-13**. Until stable, only install, build, type, public API,
accessibility and release blockers are accepted. New visual variants and animations move to
the post-release backlog.

## Distribution

### Npm runtime package

Install V3 as a regular semver-managed component package:

```bash
pnpm add poyraz-ui@3
```

```tsx
import { Button } from "poyraz-ui/atoms";
import { Dialog } from "poyraz-ui/molecules";
import "poyraz-ui/preset.css";
```

Stable `3.0.0` moves npm `latest` to V3. The final V2 release remains available through
`poyraz-ui@legacy-v2`.

### Source registry — Own the source

Choose the registry when the application should own and edit component source:

```json
{
  "registries": {
    "@poyraz": "https://ui.poyrazavsever.com/r/{name}.json"
  }
}
```

```bash
pnpm dlx shadcn@latest add @poyraz/button
```

Npm and registry are official V3 channels generated from the same canonical component source.

## Included

- ESM, CJS and TypeScript npm component package with root and layer subpath exports.
- Source registry theme, utility, recipe, hook, component and block distribution.
- Semantic light/dark/glass tokens with fallback and reduced-motion policies.
- Atom, molecule, organism and application block catalog.
- Responsive documentation previews and component playgrounds.
- Package/registry schema, graph, path and clean-install validation.
- Unit, DOM, accessibility, keyboard, focus, visual, context and performance gates.
- Incremental V2 migration mappings, audit tools and safe import codemod.

## Breaking Change

V3 changes default design tokens, component styling, variants and parts of the public component
contract. Package consumers can keep supported package import paths, but must review the
[V2 to V3 migration guide](/docs/migration) for removed/renamed behavior and visual changes.

Registry consumers install local source and own future merges. Moving from npm imports to local
registry files is optional, not a requirement for using V3.

## Release Gates

The release requires synchronized package/registry output, npm tarball installation in clean
Next/Vite consumers, registry schema and graph validation, all quality suites, docs production
build, release checksums and protected production approval.

## V2 Support

- Install fallback: `pnpm add poyraz-ui@legacy-v2`.
- Release-blocking fixes through 2027-03-31.
- End of maintenance on 2027-06-30.
- Legacy documentation remains available at `/docs/legacy/v2`.
