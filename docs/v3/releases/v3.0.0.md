# Poyraz UI Registry v3.0.0

Status: stable candidate. The immutable tag and production smoke are created by the protected release workflow.

## Distribution

V3 is a source registry, not a replacement runtime component barrel. Configure the production namespace:

```json
{
  "registries": {
    "@poyraz": "https://ui.poyrazavsever.com/r/{name}.json"
  }
}
```

Install only the source required by the application:

```bash
pnpm dlx shadcn@latest add @poyraz/button
```

The existing `poyraz-ui@2.1.x` package remains the legacy V2 runtime line. Stable V3 does not silently replace its component exports and does not move npm `latest`; the release workflow can add the explicit `legacy-v2` tag.

## Included

- Registry-first theme, utility, recipe, hook, component and block distribution.
- Semantic light/dark/glass tokens with fallback and reduced-motion policies.
- Atom, molecule, organism and application block catalog.
- Responsive documentation previews and component playgrounds.
- Registry schema, dependency graph, file path and clean-install validation.
- Unit, DOM, accessibility, keyboard, focus, visual, context and performance gates.
- Incremental V2 migration mappings, audit tools and safe import codemod.

## Breaking Change

V3 components are copied into the consumer repository. Imports such as `poyraz-ui/atoms` are not converted into a new runtime barrel. Install the corresponding registry item and import the local file instead.

Review the [V2 to V3 migration guide](/docs/migration) before removing the legacy package.

## Release Gates

The release workflow requires synchronized generated registry output, schema and graph validation, all quality suites, isolated Next/Vite installs and builds, docs production build, release checksums and a protected production environment approval.

## V2 Support

- Release-blocking fixes through 2027-03-31.
- End of maintenance on 2027-06-30.
- Legacy documentation remains available at `/docs/legacy/v2`.
