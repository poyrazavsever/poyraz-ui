# Poyraz UI v3.0.0-rc.1

Status: release candidate.

This RC validates the final V3 npm package and source registry distribution before stable
`3.0.0`.

## Included

- `poyraz-ui` npm runtime package with ESM, CJS and TypeScript declarations.
- Root, atoms, molecules, organisms, themes and `preset.css` package exports.
- `@poyraz` source registry generated from the same canonical component source.
- Tarball artifact, checksum and package file metadata.
- Clean Next.js and Vite tarball consumer smoke.
- Protected npm publish workflow with `next`, `latest` and `legacy-v2` dist-tag policy.

## RC policy

Only install, build, type, public API, accessibility and release blocker fixes are accepted during
the RC window. Cosmetic design updates and new variants stay in the post-stable backlog unless
they fix a release blocker.

## Validation

Run the protected `V3 Release` workflow with:

```text
version: 3.0.0-rc.1
channel: rc
publish_release: true
promote_legacy_v2: false
```

The workflow publishes to npm `next` only after artifact review and protected environment
approval.
